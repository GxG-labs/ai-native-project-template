# Правила проекта

Единственный источник правил работы агентов в этом проекте.

Этот файл редактирует только человек по явному запросу. Агент не меняет его
по собственной инициативе.

## Старт работы

1. Прочитайте `PROJECT.md`.
2. Прочитайте `ai/context.md`.
3. Прочитайте `ai/methods/organization.md` и `PROJECT_STRUCTURE.md`.
4. Загрузите только владельцев, которые соответствуют задаче:

   - компиляция знаний — `ai/methods/knowledge-compilation.md` и
     `ai/workflows/compile-knowledge.md`;
   - Gauntlet Loop — `ai/workflows/gauntlet-loop.md` и записи нужного
     `docs/gauntlet/<scope>/`;
   - повторяемая процедура — её `ai/skills/.../SKILL.md`;
   - многошаговый процесс — нужный файл из `ai/workflows/`;
   - проверка качества — нужный файл из `ai/checklists/`, когда он есть.

Если владелец поведения неясен, остановитесь до редактирования и определите
его. Не исправляйте метод, skill или workflow в обход владельца правила.

## Принципы

1. Сохраняйте намерение. Перед рискованным действием с неясной целью задайте
   один точный вопрос.
2. Организуйте по роли файла, а не по формату или дате создания.
3. У каждого правила, состояния и процедуры есть один владелец. Компоненты
   ссылаются друг на друга, но не копируют содержание.
4. Создавайте папки только для реальных файлов.
5. Сырые знания, playbook и skill — разные слои. Не удаляйте источники после
   компиляции.
6. Gauntlet-цикл заканчивается только изменением системы и свежей проверкой.
7. Защищайте приватные данные и секреты по `PRIVACY.md` и `SECURITY.md`.
8. Skills должны быть переносимы и не зависеть от конкретного AI-продукта.
9. **Исполняйте обязательные правила программно.** Если процесс требует
   постоянства, точности или безопасных побочных эффектов, его инварианты,
   обязательные действия, переходы состояния и постпроверки должны быть
   частью execution harness, workflow или CI. Не оставляйте их пожеланием в
   prompt: LLM может предложить намерение, но harness должен проверить его,
   выполнить разрешённые детерминированные действия и зафиксировать результат.

## Адаптеры

`AGENTS.md`, `CLAUDE.md`, `GEMINI.md` и аналогичные файлы инструментов —
только адаптеры. Они содержат ссылку на этот файл, а не собственные правила.
Скрытые папки инструментов не хранят содержательные инструкции или проектную
документацию.

## Поведение агента

- Думайте, формулируйте промпты и ищите на английском.
- Отвечайте пользователю и пишите понятные человеку файлы по-русски.
- Не меняйте файлы вне запроса и не создавайте абстракции «на будущее».
- Для значимого изменения оставляйте проверяемое доказательство: тест,
  eval, проверку артефакта или наблюдаемый результат.

## Завершение изменения

Перед завершением убедитесь, что:

- изменение сделано у владельца;
- адаптеры не получили копию правила;
- ссылки и связанные workflow не устарели;
- результат проверен соразмерно риску;
- оставшаяся неопределённость явно названа.
