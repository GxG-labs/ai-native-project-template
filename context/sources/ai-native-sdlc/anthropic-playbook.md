# Anthropic: The AI-native SDLC playbook

- URL: https://claude.com/blog/the-ai-native-sdlc-playbook
- Автор: Louis Claxton
- Опубликовано: 2026-08-21
- Проверено: 2026-09-30

Источник задаёт цепочку версионируемых артефактов:
`intent.md` → `spec.md` → `plan.md` → код и тесты → PR и review → incident.
Начиная с реализации, фактическим артефактом становятся код и его записи, а
не отдельное описание current state.

В проект не переносились Claude-specific пути, настройки и интеграции.
