# Размещение файлов

Полная карта папок принадлежит `PROJECT_STRUCTURE.md`. Этот метод нужен только
для выбора роли файла.

1. Спросите, на какой вопрос отвечает файл сейчас.
2. Поместите его в папку, которая отвечает на этот вопрос в карте структуры.
3. Если результат станет входом следующего процесса, перенесите его к новой
   долговременной роли, а не оставляйте в `output/`.
4. Для растущего знания используйте цепочку source → playbook → skill.
5. Для изменяемой системы храните цель в дереве `docs/spec/<scope>/` с
   входом `spec.md`, а разрывы и доказательства текущего состояния — в
   Gauntlet. Не пересказывайте текущую реализацию отдельно от кода, тестов и
   конфигурации.

Не создавайте папку до появления файла, который это оправдывает. Решение о
`README.md` принимайте по навигационному правилу из `PROJECT_STRUCTURE.md`.
