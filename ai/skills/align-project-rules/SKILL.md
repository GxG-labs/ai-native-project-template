# Выравнивание проекта

1. Прочитайте `RULES.md` и все источники, на которые он направляет для этой
   задачи.
2. Найдите дубли правил, смешанные роли файлов, пустые папки и адаптеры,
   которые содержат больше ссылки на `RULES.md`.
3. Для каждого файла определите роль по `ai/methods/organization.md`.
4. Внесите наименьшее изменение, которое оставляет одно место-владельца для
   каждого правила, состояния и процедуры.
5. Проверьте ссылки, структуру и отсутствие устаревших копий.

Не переносите файл, если его роль нельзя определить по проектным источникам
или запросу пользователя.
