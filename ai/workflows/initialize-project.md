# Инициализация проекта

1. Заполните `PROJECT.md`: результат, критерии успеха, границы и текущий
   фокус.
2. Заполните `ai/context.md` только устойчивыми фактами и ограничениями.
3. Создайте первую задачу в `intent/` и только те папки, которые она требует.
4. Для изменения ПО следуйте `ai/workflows/software-change.md`; создавайте
   spec и plan только когда они нужны задаче.
5. Если задача опирается на растущее знание, начните с
   `ai/workflows/compile-knowledge.md`.
6. Если задача меняет систему итеративно, создайте её Gauntlet-контур по
   `ai/workflows/gauntlet-loop.md`.
7. Добавьте код, данные, документацию, проверки и автоматизацию только после
   того, как для них появился конкретный владелец и задача.

Проект готов к работе, когда его цель понятна, первая задача определена, а
обязательные ограничения не остаются догадками.
