# Self Improve

Choose different actions by default. Propose one working-instruction change only for repeated errors, accumulated general evidence or explicit human direction. Submit approved amendments through cycle method; the executor records a three-complete-pass trial and keep/revert. Never change criteria automatically.

Read ../../README.md for the executable protocol. These notes do not replace the runtime or create a separate manual workflow.
