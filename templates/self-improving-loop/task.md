# Task setup notes

Define the desired outcome, acceptance criteria, permitted actions and objective checks in config.json and the task adapter before initialization. Use target=1 when one deliverable must pass all criteria. The included configuration is a local sample demonstration, not an unfilled task.

After initialization, SQLite owns the task configuration and criteria versions. Submit changes through the documented CLI rather than keeping a competing task definition in Markdown. This file can hold setup rationale and references; it is not an execution checkpoint.
