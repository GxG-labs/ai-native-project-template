# Run program

## Goal

Deliver the result in `task.md` through measured iterations. The task owner decides the desired result and allowed scope.

## Rules

- Read project `RULES.md` and the relevant owner workflow before work.
- Make the smallest system change that can satisfy one acceptance criterion.
- Keep or revert each candidate using the checks in `task.md` and any relevant existing checks. Never claim an unchecked result.
- Revert only changes made by this run; preserve unrelated work.
- After each candidate, record a concrete lesson and improve only a run instruction, context fact, or check that the next iteration actually reads. Change `program.md` only as a proposal for owner review.
- Stop for deployment, money, external actions, irreversible operations, security-sensitive access, or scope changes requiring a human decision.

## Measures

Record iteration count, check results, elapsed time if available, and acceptance criteria passed in `execution_state.md`.
