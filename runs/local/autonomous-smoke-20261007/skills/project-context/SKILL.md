# Project context

Read project `RULES.md` and its required context files in order, then `task.md`, `program.md`, relevant `lessons.md` entries, and the current `execution_state.md`. Read the project files relevant to the task. Refresh `PROJECT_CONTEXT.md` with sourced, current facts only. If a required fact is unknown, record it as unknown and resolve it before a risky change.
