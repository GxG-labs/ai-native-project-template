# Self improve

Read `execution_state.md` and relevant `lessons.md` entries. Add one concrete entry: observation, cause, next-use action, and measure. If evidence shows a repeatable weakness, make one minimal improvement to a file the next outer iteration actually reads: a run skill, `PROJECT_CONTEXT.md`, or a reusable check. Validate the improvement before keeping it. Propose any change to `program.md` to the task owner; do not silently change goals, boundaries, or human gates. Skip edits that have no observed benefit.
